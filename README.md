# DJ TONII --- Publicar la web

## Objetivo

Convertir el enlace local de la web DJ TONII en un enlace público y
bonito para compartirlo en Instagram, TikTok y otras redes sociales.

## Importante

El enlace local:

``` text
file:///C:/Users/anton/.../index.html
```

solo funciona en el ordenador donde está guardada la web. Si se comparte
en redes sociales, otras personas no podrán acceder a él.

## Recomendación: publicar la web en Netlify

Netlify permite alojar una web estática y obtener un enlace público que
se puede abrir desde cualquier dispositivo.

### Pasos

1.  Entra en [Netlify Drop](https://app.netlify.com/drop).
2.  Descomprime el archivo ZIP de la web.
3.  Arrastra la carpeta de la web a Netlify.
4.  Espera a que termine la publicación.
5.  Copia el enlace público generado.
6.  Comparte ese enlace en tus redes sociales.

### Ejemplo de enlace

``` text
https://djtonii.netlify.app
```

Este es únicamente un ejemplo. El enlace final lo generará Netlify al
publicar la web.

## Dominio personalizado

Para conseguir una dirección más profesional, puedes comprar o
configurar un dominio personalizado, por ejemplo:

``` text
https://djtonii.com
```

La disponibilidad del dominio debe comprobarse antes de registrarlo.

## Resultado esperado

La web DJ TONII tendrá un enlace público, fácil de compartir y accesible
desde móviles, tablets y ordenadores.
